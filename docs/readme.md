# Dhammapada — 法句经

A bilingual study site for the Dhammapada, one of the most beloved texts in Theravada Buddhism.

## About the text

The Dhammapada (法句经, *Fǎ Jù Jīng*) is a collection of 423 verses attributed to the Buddha, organized into 26 chapters (vaggas). Each chapter groups verses around a theme — the mind, the fool, the wise, the path, craving, and more. It is one of the most widely read texts in the Pali Canon and a foundational scripture of Theravada Buddhism.

## About this site

- **26 chapters**, one page per chapter
- **Primary text**: Classical Chinese 法句经
- **Chinese explanations**: Modern, accessible Chinese (always visible)
- **English**: Buddharakkhita translation + commentary (toggle to reveal)
- **Speech**: 🔊 聆听经文 button reads the Chinese text aloud
- Part of [The Dharma Gate](https://lugh3456.github.io/DharmaGate/) portal
